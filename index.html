Problem & Context

High-traffic public and enterprise service environments (e.g. major healthcare clinics, hospitals, and busy restaurants) experience severe bottlenecks when physical queues and mobile appointments desynchronize. The platform needed to support 650,000+ registered user accounts and 60+ microservices without latency spikes during peak rush hours.

Engineering Solution

Architected a unified backend with Node.js and Sails.js handling both synchronous REST APIs and event-driven WebSocket streams. Replaced slow Waterline ORM queries with native PostgreSQL commands and MongoDB aggregation pipelines, cutting ticket endpoint latency to ~200ms. Offloaded notification delivery and heavy processing to AWS SQS worker queues and 10–15 automated cron jobs.

Key Backend Architectural Decisions
  • Decoupling Notifications via AWS SQS: Prevented API latency spikes during mass ticket alerts by enqueueing push/SMS events onto SQS worker queues.
  • Native SQL & Aggregations: Bypassed ORM abstraction on performance-critical ticket lookups, achieving ~200 ms response times measured in Postman.
  • Multi-Channel Push Strategy: Supported APNs Live Activities on iOS for dynamic lock-screen ticket position countdowns alongside FCM and Huawei Push Kit from the ground up.

KnowledgeBase AI

Full-Stack Retrieval-Augmented Generation & Vector Search Engine

KnowledgeBase AI is a full-stack Retrieval-Augmented Generation platform that allows users to upload documents and ask AI questions based on their content, with semantic retrieval, contextual responses, source citations, conversation history, and real-time streaming.

The Problem

Traditional document search often relies on keyword matching and makes it difficult to ask natural-language questions across large collections of documents. Users cannot easily pinpoint exact citations across PDFs, text documents, or scanned images.

The Engineering Solution

Built an end-to-end RAG pipeline that converts uploaded documents into searchable vector representations, stores them in PostgreSQL with pgvector, executes cosine similarity retrieval for relevant context, and generates grounded streaming responses via Ollama.
